# SheepCatcherAI 🐑

As part of the **CowCatcherAI** open-source ecosystem, **SheepCatcherAI** is the newest member of the family. This repository is specifically tailored for sheep farmers, focusing on automated **lambing (birth) detection**.

By combining computer vision and local AI agents, SheepCatcherAI provides real-time insights and instant notifications to help farmers protect their ewes and lambs during crucial moments.

---

## 🔄 How it Works

📷 Lambing Pen Camera  ──→ 🤖 AI Computer Vision (YOLO) ──→ ⚡ Lambing Detection ──→ 💽 Save Event Image ──→  📲 Telegram Notification with Image & video

---

## 🚀 Features & Technology

We combine multiple cutting-edge, open-source technologies to create a reliable monitoring system that runs on the core [AI Detector](https://github.com/ESchouten/ai-detector) software:

* **Computer Vision:** Powered by **Ultralytics YOLO** for real-time tracking and behavior detection (labor positions, restlessness, lambing).
* **Smart Alerts:** Instant Telegram notifications including the captured image and the AI agent's expert reasoning.
